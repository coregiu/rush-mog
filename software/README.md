# 1 整体软件架构
RushMog智能系统包括语音控制系统，车体控制系统，视觉分析系统，远程控制中心系统、激光雷达系统、VLA推理系统、机械臂系统六个核心子系统。
- 语音控制系统，识别语音，将语音转换成执行指令，并将指令传给主控制系统，进行控制执行。(原计划采用asr-pro车载控制，但小车电机噪音较大，效果不好。改用终端控制。)
- 车体控制系统，STM32单板控制，接收语音指令、PS2手柄指令对小车行进、声音、机械臂进行控制执行。
- 远程控制中心系统，提供WIFI供终端连接，提供PS2手柄页面的WEB Server，接收摄像头监控图像推送到终端PS2页面上，同时提供模拟PS2手柄的各项指令操作。
- 激光雷达系统。 待实现
- VLA推理系统。 待实现
- 机械臂系统。 待实现

# 3 子系统设计说明
## 3.1 语音控制子系统
[语音控制系统](audio_control/README.md) 

## 3.2 车体控制子系统

[车体控制系统](body_control/README.md)

车体控制子系统功能：
- 1 接收语言控制指令
- 2 驱动小车电机，四个电机分别驱动，能够实现前进/后退/停止等动作
- 3 与树莓派/摄像头交互，传递控制指令，接收图像分析结果
- 4 驱动机械臂运动控制执行


## 3.3 远程控制子系统
- [远程控制子系统](remote_center/README.md)

远程控制子系统功能：
- 1 连接摄像头，实时采集图像数据
- 2 应用机器学习进行图像识别
- 3 对位置、距离进行识别
- 4 形成控制指令传给主控制系统
